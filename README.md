# AprendeMejor — Sitio de Métodos de Estudio

Sitio web sobre métodos de estudio, construido en HTML/CSS/JS puro.

## Estructura del proyecto

```
sitio-metodos-estudio/
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos (variables de diseño al inicio del archivo)
├── js/
│   └── script.js       # Comportamiento del menú móvil
├── assets/
│   └── img/            # Imágenes del sitio
└── README.md
```

## Cómo trabajarlo en equipo con Git

1. Clona el repositorio: `git clone <url-del-repo>`
2. Crea una rama por cada funcionalidad o sección que trabajen:
   `git checkout -b nombre-de-la-rama`
3. Antes de empezar a trabajar cada día, trae los últimos cambios:
   `git pull origin main`
4. Haz commits pequeños y descriptivos:
   `git commit -m "Agrega sección de recursos"`
5. Sube tu rama y abran un Pull Request para revisar los cambios antes de fusionar a `main`, así evitan pisarse el trabajo.

## Cómo verlo localmente

Abre `index.html` directamente en el navegador, o usa la extensión **Live Server** de VS Code para recarga automática mientras editas.
